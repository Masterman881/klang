# VERS

Ein eigener Musikplayer als Web-App – mit Songtexten, Hörstatistik, Smart Shuffle und Überblenden. Offline, werbefrei, kostenlos.
Spielt eigene Musikdateien (MP3, M4A, FLAC, OGG, WAV) direkt im Browser ab.
Die Musik bleibt auf dem Gerät und wird nirgendwo hochgeladen.

Dazu kommen legale, kostenlose Online-Quellen:
- **Entdecken:** vollständige Songs von [Audius](https://audius.co), wo Künstler ihre Musik selbst zum Streamen freigeben
- **Radio:** tausende Live-Sender aus dem Verzeichnis von [radio-browser.info](https://www.radio-browser.info)

**Installieren:** Seite öffnen → Android: Menü ⋮ → „App installieren“ · iPhone: Teilen → „Zum Home-Bildschirm“.
